# MakingFaces v1.0.0 — Wayland/SDL2 Animatronic Face Compositor & Art-Net/sACN Engine

**Architecture & C++17 Engine by Magnus Herrlin (2026)**  

MakingFaces is a real-time 600x800 animatronic character compositor featuring dual procedural eyes, 3D anti-aliased lips and teeth, a 3-depth weather/FX engine with 20 effects, stereo system loopback and `.wav`/`.mp3` lip-sync, 4-mode Art-Net/sACN DMX control, and live calibration tools.

Full documentation is available in **INSTALL.md**, **USER_MANUAL.md**, and **MANUAL.html**.
